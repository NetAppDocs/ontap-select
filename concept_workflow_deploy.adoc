= ONTAP Select installation and deployment workflow
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
You can use the following workflow to deploy and administer an ONTAP Select cluster.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png[One] link:reference_plan_ots_general.html[Plan the deployment and prepare the environment]
[role="quick-margin-para"]

Review the planning requirements for your ONTAP Select nodes, storage, networking, and hypervisor environment. Preparing your environment in advance helps you avoid deployment issues.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png[Two] link:task_install_deploy.html[Install the ONTAP Select Deploy administration utility]
[role="quick-margin-para"]

Install the utility that you use to deploy and manage ONTAP Select clusters.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png[Three] link:concept_lic_workflow.html[Acquire the licenses required for a production deployment]
[role="quick-margin-para"]

Purchase and apply the licenses needed for your production deployment. You can choose between the Capacity Tiers and Capacity Pools licensing models.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png[Four] Deploy an ONTAP Select cluster using the ONTAP Select Deploy administration utility 
[role="quick-margin-para"]

Use the Deploy utility to create your ONTAP Select cluster:

[role="quick-margin-list"]
* link:task_deploy_cluster.html[Deploy using the web UI]
* link:task_cli_deploy_cluster.html[Deploy using the CLI]

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png[Five] link:concept_adm_before.html[Administer the ONTAP Select cluster using the standard NetApp management tools and interfaces]
[role="quick-margin-para"]

Administer your ONTAP Select cluster using the same management tools and interfaces you use for other ONTAP clusters.
